Mission Overview

Aegis is the web interface of Project Sentinel: a machine-learning model trained on NASA close-approach data that flags Near-Earth Objects as Hazardous or Non-hazardous.

Model Intelligence

How it works

An XGBoost classifier learns from past NASA records how size (absolute magnitude), speed and flyby distance combine. It outputs a hazard score between 0 and 1; scores above a tuned threshold are labelled Hazardous.

The score is a model output, not the probability of an impact. NASA's official label also uses orbital data (MOID) that is not in this dataset, which limits accuracy.
